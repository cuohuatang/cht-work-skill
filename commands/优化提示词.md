请使用 **cht-work-skill** 的第一步「提示词优化」能力，按 `references/prompt-architect.md` 执行，元提示词原文一字不改。

用户输入：$ARGUMENTS

## 执行要点
1. **先过禁止优化清单**：寒暄致谢 / 纯事实问答·翻译·摘要 / 延续性修改 / 已点名技能或文件 / 只要判断——命中任一项则**禁止输出两版**、直接回应，并说明「命中禁止优化类，本轮不生成两版」。
2. 未命中则按四件事执行：补齐隐性需求（角色 / 受众 / 风格 / 格式 / 验收 / 边界，缺失按保守默认并标假设，不反问）、出两版（精简通用版 ≤120 字单段 / 高阶顶配版分段结构化）、结构化排版、适配 ChatGPT / Claude Code / 豆包 / DeepSeek / Kimi / harness 等所有 Agent 并规避逻辑漏洞。
3. 输出规格固定四块：精简通用版 / 高阶顶配版 / 隐性需求补齐表 / 已规避的漏洞清单。两版之外不输出第三版。
4. 不废话、不寒暄、不凑字数。

若 $ARGUMENTS 为空，先问：你要让 AI 做什么、用在什么场景？口语说就行。
