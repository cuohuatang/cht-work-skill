请使用 **cht-work-skill** 第五步的 **Inspecto**（进阶前端工具）执行，细则见 `references/visual-feedback-routing.md`。

用户输入：$ARGUMENTS

## 何时用这个（而不用 /改网页）
默认用 Pinta（`/改网页`）就够。只有需要以下任一项才上 Inspecto：
- `Alt + 点击` 跳到准确源码行；
- 看 Agent 任务时间线（session 状态实时回传：领取 / 处理中 / 完成 / 忽略）；
- `prompts.json` 自定义工作流按钮（如 Deploy Preview / Review & PR）。

## 执行要点
1. 项目根目录装 CLI：``npm install -D @inspecto-dev/cli``（我引导配置），重启 dev server，浏览器打开页面。
2. 三模式：Quick Jump / Inspect Mode / Annotate Mode。告诉用户怎么点选、怎么跳源码行。
3. **配置细节查官方文档，不凭空编造 `prompts.json` 字段**——官方 overview 页未给出完整 schema，未确认的键名不乱写。
4. 读回批注 → 先 Plan 后改 → 按 Ponytail 七级阶梯写最小代码 → 刷新核验。
5. **诚实边界**：Inspecto 是前端工程化工具，PPT / Word / Markdown / 图片文档不走它（用 `/改文档`）；它是外部可选依赖，未装时给官方入口、不阻塞。

若 $ARGUMENTS 为空，先问：前端项目在哪个目录？需要跳源码行 / 看时间线 / 自定义工作流中的哪项？
