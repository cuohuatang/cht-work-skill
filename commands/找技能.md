请使用 **cht-work-skill** 的第二步「任务前置分流」能力，按 `references/skill-first-workflow.md` 执行。

用户输入：$ARGUMENTS

## 执行要点
1. 先确认 find-skills 已全局安装（`grep -rl "^name: find-skills" ~/.codebuddy/skills/*/SKILL.md`）；没有先装。
2. 把任务描述转成中英两组检索词，调用语义检索：
   ```bash
   curl -s "https://lightmake.site/api/v1/search?q=<URL编码后的需求>&limit=10"
   ```
3. 按阈值判定并给出动作：
   - **≥ 0.90**：高相似，现成技能可用 → 直接复用，不自造；
   - **0.60~0.90**：列候选 + 差异，用户点名才用；
   - **< 0.60**：无现成技能 → 自主实现，写明「已检索、无高相似技能」。
4. 留痕：检索词 / 最高 score / 阈值判定 / 结论。
5. 若任务明确落在网页 PPT 域，本仓库两条路线就是已匹配能力，直接说明，不必为同一需求重复检索。

若 $ARGUMENTS 为空，先问：你要做什么任务？我用它找现成技能。
