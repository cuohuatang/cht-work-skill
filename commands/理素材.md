请使用 **cht-work-skill** 的第零步「素材工作台」能力，按 `references/weknora-knowledge-workbench.md` 执行。

用户输入：$ARGUMENTS

## 执行要点
1. 先判定是否需要这一步：素材散落多格式 / 要带引用核实 / 要先理大纲找依据 → 需要；单一文件 / 明确主题 → 不必，直接用简单方式，别把轻量任务塞进重型知识库。
2. **诚实边界**：本技能不部署 WeKnora、不内置运行时、不要求用户安装。用户已有实例（含 MCP `/mcp/<id>`）就把检索结果当素材输入；没有就用本地脚本 / 直接读文本整理，不阻塞。
3. 输出：整理后的大纲 / 依据清单，**带出处引用**，可直接喂给 `/优化提示词` 或两条 PPT 路线。
4. 许可口径：WeKnora 主体 MIT + 第三方组件各自许可（API 标记 NOASSERTION），别写成纯 MIT。

若 $ARGUMENTS 为空，先问：要整理哪些资料（路径 / 链接 / 来源）？想理成什么？
