# 项目速记表

供 `/改`（及 `/fix`、`/改网页` 等命令）在运行时匹配项目别名用。命中后直接用记录的路径 / 启动命令 / URL，不再重复询问。

## 用法

- 用户说「改报价器」「改那个报价网页」等带别名的话 → 在下表按别名匹配（支持模糊包含）。
- 命中 → 取该项目行的「类型 / 路径 / 启动命令 / 页面 URL」，直接进入对应工具的标注流程，跳过选择框。
- 未命中但用户给了路径 → 执行完顺手在下表补一行（别名由用户给的名字提炼）。
- 未命中且没路径 → 问一次，拿到后先记一行再执行。**这是唯一一次需要用户提供路径，之后永久记住。**
